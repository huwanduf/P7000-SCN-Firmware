## 简体中文

**历史归档，不是最新固件。** [最新 v3.4.3 候选](https://github.com/huwanduf/P7000-SCN-Firmware/releases/tag/v3.4.3)。本版从最新版下载页独立拆出，固件及原 SD 压缩包字节均未改变。

- **适配机型与基础版本：** 仅 Nikon COOLPIX P7000，首次安装前先升级官方 **1.2**；相机仍显示 1.2。
- **本版功能：** 包含全 SCN NRW+JPEG、场景原厂 WB 上的共享两轴 ±2 微调、共享 ISO 和记忆，以及兼容的 AF、测光、失真控制和动态 D-Lighting。
- **适合需求：** 适合需要共享 WB/ISO 和记忆及兼容我的菜单控制，同时保留原始场景优化校准的用户。
- **保留限制：** SCN 优化校准灰显并采用场景原始值；最低快门与连拍沿用场景策略。不含 WB ±6、风景自动闪光或自定义电量显示；菜单/取景卡顿仍在。
- **实机反馈范围：** 用户确认“完全可用”，继而请求性能研究；这是用户反馈，非逐场景独立验证。

下载 **P7000-v3.2.2-SD.zip** 并解压，将 **firmware 文件夹整体拖到 SD 卡根目录**，得到 `firmware/firmware.bin`。电量充足时进入设置 → 固件版本 → 更新，期间保持供电；不必逐版升级。较新版本回退到早期版本时，共享 SCN 设置可能恢复安全默认，需要重设。

此标签的 Source code 压缩包也包含对应版本的固件和说明，不会混入 v3.4.3 固件。标签是本次新建的历史归档标签，不代表原始开发提交历史。完整持续研究源码包仍在最新版 Release 提供。
