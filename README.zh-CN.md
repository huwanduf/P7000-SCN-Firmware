## 简体中文

**历史归档，不是最新固件。** [最新 v3.4.3 候选](https://github.com/huwanduf/P7000-SCN-Firmware/releases/tag/v3.4.3)。本版从最新版下载页独立拆出，固件及原 SD 压缩包字节均未改变。

- **适配机型与基础版本：** 仅 Nikon COOLPIX P7000，首次安装前先升级官方 **1.2**；相机仍显示 1.2。
- **本版功能：** 在 v3.2.2 基础上把共享 WB 两轴扩大至 ±6，迁移旧版 WB/ISO 记录，并为风景增加自动/关闭闪光；保留 RAW+JPEG、ISO 记忆和已有兼容菜单。
- **适合需求：** 适合需要 WB ±6 和风景自动闪光、但希望保持原厂电池显示的用户。
- **保留限制：** 风景初始化仍默认关闭闪光，需要时弹起闪光灯并选择自动。优化校准/最低快门/连拍保留场景策略。不含五档电池设置；未证明消除黑屏或整体提速。
- **实机反馈范围：** 用户确认除卡顿外其他非常完美；无逐项独立实拍报告。

下载 **P7000-v3.3-SD.zip** 并解压，将 **firmware 文件夹整体拖到 SD 卡根目录**，得到 `firmware/firmware.bin`。电量充足时进入设置 → 固件版本 → 更新，期间保持供电；不必逐版升级。较新版本回退到早期版本时，共享 SCN 设置可能恢复安全默认，需要重设。

此标签的 Source code 压缩包也包含对应版本的固件和说明，不会混入 v3.4.3 固件。标签是本次新建的历史归档标签，不代表原始开发提交历史。完整持续研究源码包仍在最新版 Release 提供。
