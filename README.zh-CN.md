# P7000 SCN Firmware

[English](README.md) | **简体中文**

为 **Nikon COOLPIX P7000** 扩展 SCN 场景模式：在保留场景原有处理风格的基础上，加入 NRW+JPEG、共享白平衡微调和 ISO、兼容的“我的菜单”控制，以及五档电量图标。

本项目以官方 **1.2** 为基础。项目发布号与相机版本号分开：当前为 **v3.4.3**，相机中仍显示 **1.2**。仅适用于 P7000。

## 安装：先官方 1.2，再复制 firmware 文件夹

1. **首次使用本项目，先把相机升级至尼康官方 1.2。** 原厂已经是 1.2 的相机可跳过这一步。[官方 1.2 下载与说明](https://downloadcenter.nikonimglib.com/zh-cn/download/fw/45.html)。
2. 下载并解压本项目的 **SD 升级包**。将解压得到的 **`firmware` 文件夹整体拖入 SD 卡根目录**。
3. 正确结构为 `SD卡根目录/firmware/firmware.bin`。不要把 ZIP、项目外层目录或单独的 bin 放到错误位置。
4. 使用电量充足的电池，将卡插入相机，进入 **设置 → 固件版本 → 更新**，按屏幕提示完成。更新期间不要断电。
5. 完成后正常关机、取出存储卡再开机。自定义版本仍显示 1.2，请按本项目功能和下载校验值区分版本。

完整步骤及回退注意事项见 [安装说明](docs/installation.zh-CN.md)。下载 GitHub 的 Source code ZIP 或克隆本仓库时，同样只把其中的 `firmware` 文件夹复制到卡根目录。

## 当前功能

| 功能 | v3.4.3 行为 |
|---|---|
| SCN NRW+JPEG | 开放全部 SCN 菜单项，沿用原厂尺寸和特殊拍摄兼容检查 |
| 白平衡 | 在各场景原厂 WB 上叠加共享的两轴 **±6 档**微调，关机记忆；SCN 直接进入微调页 |
| ISO | 共享合法 ISO 选项并记忆；最低快门由所选场景程序判断 |
| 我的菜单 | 保留六槽内容及顺序，按兼容条件开放 AF、测光、失真控制、动态 D-Lighting |
| 风景闪光 | 增加自动闪光选项，保留场景初始化规则 |
| 电池图标 | 五档显示；超低电量为**红色一格**，原厂低电警告与关机保护保留 |
| 电池开关 | **设置 → 监视器设置 → 照片信息**，电池列在水平仪左侧；两行分别控制显示/隐藏信息画面 |

希望两种取景画面始终显示电池，请将电池列的上下两格都勾选，再移到原来的“确认”按 OK。MENU 直接返回会取消本页尚未确认的修改。单张回放本页沿用“显示信息”一行。

五格仍读取原厂七个粗估档：100→5 格，80/65→4 格，50→3 格，25→2 格，5/2→红色 1 格。**它不是更精确的电池容量测量，也不是固定满电图标。** 缓存更新仍由原厂事件驱动，实际更新间隔未测量。

## 保留 SCN 风格与老平台的运行边界

SCN 的独特之处在于场景程序对色彩、曝光、降噪与连拍的组合处理。本项目优先保留这条处理链，开放已经确认兼容的调整，不把 SCN 整体切换成 P/A/S/M。

因此，SCN 优化校准采用场景原始值，最低快门沿用场景曝光程序，连拍保留各场景原有策略。考虑这代平台的资源和稳定运行要求，不提高芯片时钟、不改硬件初始化或校准区，也不直接移植 P7100 代码。上述取舍有助于控制改动范围；**并非所有未实现功能都已证实受芯片算力限制**。

早期优化校准入口出现过黑屏，已在 v3.2.2 撤回；新增连拍的画质/尺寸/ISO 恢复未充分验证，暂不加入。菜单或返回取景仍可能短暂黑屏、停顿，当前没有已验证的系统提速或黑屏消除承诺。详见 [功能取舍](docs/feature-policy.zh-CN.md) 与 [版本记录](CHANGELOG.zh-CN.md)。
