## v1 — Four-scene NRW+JPEG

**Historical archive — not the latest firmware.** [Current v3.4.3 candidate](https://github.com/huwanduf/P7000-SCN-Firmware/releases/tag/v3.4.3). This release was separated from the latest download page; its firmware and original SD ZIP are unchanged.

### Compatibility and included features

- **Camera:** Nikon COOLPIX P7000 only. Install official Nikon **1.2** first; the camera continues to report 1.2.
- **Included:** Enables NRW+Fine/Normal/Basic JPEG in Portrait, Landscape, Close-up and Food. Other scenes and RAW-only retain their original restrictions.
- **Suitable use:** For the original scene WB/ISO behavior with RAW+JPEG in just these four scenes.
- **Retained limits:** No shared WB/ISO controls, expanded My Menu, landscape Auto flash or custom battery display.
- **Hardware feedback:** The user confirmed successful updating and shooting in all four scenes; the supplied image files were not independently examined.

### Install

Download **`P7000-v1-SD.zip`**, extract it, and drag the entire **firmware** folder to the SD card root: `firmware/firmware.bin`. Use a charged battery, open Setup → Firmware version → Update, and keep power connected. Intermediate project versions do not need to be installed in order.
