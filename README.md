## v2 — All-SCN NRW+JPEG

**Historical archive — not the latest firmware.** [Current v3.4.3 candidate](https://github.com/huwanduf/P7000-SCN-Firmware/releases/tag/v3.4.3). This release was separated from the latest download page; its firmware and original SD ZIP are unchanged.

### Compatibility and included features

- **Camera:** Nikon COOLPIX P7000 only. Install official Nikon **1.2** first; the camera continues to report 1.2.
- **Included:** Extends NRW+JPEG to all 18 SCN menu entries: 17 manual scenes plus Scene Auto Selector. Native image-size and special-capture compatibility checks remain.
- **Suitable use:** For RAW+JPEG across the SCN menu while retaining the original WB/ISO and scene controls.
- **Retained limits:** Not every special-capture/size combination supports RAW. No later shared WB/ISO or battery extensions.
- **Hardware feedback:** The user reported success; this is not independent testing of all 18 scene entries or every special combination.

### Install

Download **`P7000-v2-SD.zip`**, extract it, and drag the entire **firmware** folder to the SD card root: `firmware/firmware.bin`. Use a charged battery, open Setup → Firmware version → Update, and keep power connected. Intermediate project versions do not need to be installed in order.

It is a new archival tag, not a reconstruction of the original development Git history. The ongoing research/source bundle remains on the current release page.
