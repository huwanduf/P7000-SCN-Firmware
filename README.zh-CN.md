## 简体中文

**历史归档，不是最新固件。** [最新 v3.4.3 候选](https://github.com/huwanduf/P7000-SCN-Firmware/releases/tag/v3.4.3)。本版从最新版下载页独立拆出，固件及原 SD 压缩包字节均未改变。

- **适配机型与基础版本：** 仅 Nikon COOLPIX P7000，首次安装前先升级官方 **1.2**；相机仍显示 1.2。
- **本版功能：** 扩展到全部 18 个 SCN 菜单项：17 个手动场景及场景自动选择。保留原厂尺寸与特殊拍摄兼容检查。
- **适合需求：** 适合希望全 SCN 可选 RAW+JPEG，同时保留原厂 WB/ISO 和场景控制的用户。
- **保留限制：** 并非所有特殊拍摄与尺寸组合都支持 RAW；不包含后续共享 WB/ISO 或电量扩展。
- **实机反馈范围：** 用户随后报告“完美”；不等于所有18场景和特殊组合逐项验证。

下载 **P7000-v2-SD.zip** 并解压，将 **firmware 文件夹整体拖到 SD 卡根目录**，得到 `firmware/firmware.bin`。电量充足时进入设置 → 固件版本 → 更新，期间保持供电；不必逐版升级。较新版本回退到早期版本时，共享 SCN 设置可能恢复安全默认，需要重设。

此标签的 Source code 压缩包也包含对应版本的固件和说明，不会混入 v3.4.3 固件。标签是本次新建的历史归档标签，不代表原始开发提交历史。完整持续研究源码包仍在最新版 Release 提供。
