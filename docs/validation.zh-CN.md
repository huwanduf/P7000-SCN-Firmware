# 验证范围

[English](validation.md) | 简体中文

## v3.4.3 已通过的离线检查

- 371 项照片信息菜单用例：两行独立开关、导航/旋钮、确认与取消、原六格行为。
- 218 项 OSD 用例：原厂电量值和无效值、五格/低电红一格、两种信息画面开关、显示暂停/恢复与缓存读取限频。
- 20,544 项原生参数/迁移用例：ARM/Thumb 回调、只读电量字段、非法输入、P7C4 编解码、旧记录迁移和外层恢复门。
- 固件长度、四段校验、原字节和改动边界、资源重建、来向引用、未改区域检查、实际资源装载路径的有限指令回放。
- 源码构建和独立补丁重建结果逐字节一致。

有限指令解释器使用了明确的测试替身；它不等于在真实 ARM CPU、显示硬件或 Flash 上运行。公开 research 包保留实际报告、原始源码哈希和复现说明。

## 尚待本版实机确认

电池列的实际字体/布局和遮挡、实体按键及显示切换事件、正常关机后的新开关记忆、睡眠/录像/拍摄忙状态、真实电量下降曲线与 MCU 更新间隔。原厂缓存会变化的离线证据不能证明某块电池当前还剩多少容量。

## 已有使用者反馈

四场景初版得到逐场景实拍反馈；V3 基础 WB/ISO 与关机记忆、V3.2.2 的可用性、V3.3 除卡顿外的主要功能得到使用者确认。这是使用者反馈，不是对所有组合的独立实验，也不能沿用为 V3.4.3 已验收结论。

## 公开包处理

GitHub 公开包移除了个人照片文件名/哈希证据、无用的本地路径记录及重复 staging 目录；固件、当前源码和哈希绑定保持不变。重新生成公开包文件清单并重新执行源码/补丁重建。公开仓库只放当前固件和说明，完整历史依赖在 research 资产中。
